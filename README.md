# Платформа КРИТ — MVP

Двухслойный NLP-подбор российских аналогов импортных комплектующих (демо-прототип, УГТ 3).

## Как работает
1. **Извлечение характеристик** из текста запроса или PDF-паспорта (regex + словари): размеры, ток, полюса, давление, подача/напор, сигнал, IP, стандарт, артикул.
2. **Семантическое сопоставление**: нейросеть `intfloat/multilingual-e5-base`; без интернета автоматически включается лёгкий `lexical`-режим (символьные n-граммы, только numpy). Выбор: `KRIT_EMBEDDINGS=auto|e5|lexical`.
3. **Взвешенный скоринг** (веса в `nlp_matcher.WEIGHTS`): параметры 35% + семантика 30% + название 10% + артикул 10% + стандарт 5% + материал 5% + категория 5%. Учитываются только слои, по которым есть данные.
4. **Вердикт** по каждому аналогу: «совпадает полностью» / «требует проверки инженером» + список совпавших и отличающихся параметров.
5. **Предложения поставщиков**: цена, наличие, срок (в демо данные вымышленные).

## Страницы и API
- `/` — поиск аналогов по тексту, загрузка PDF-паспорта.
- `/erp` — макет закупочной заявки в стиле 1С с кнопкой «Подобрать аналог».
- `POST /api/match`, `POST /api/extract-pdf`, `GET /api/erp/demo-request`, `GET /api/catalog/stats`, `GET /api/health`.
- `/engineer` — кабинет инженера: согласование или отклонение замен со сверкой характеристик и журналом решений. Закупщик в `/erp` не меняет позицию сам, а отправляет предложение инженеру; если аналог «требует проверки», для согласования нужен комментарий. Данные хранятся в SQLite (`data/krit.db`, создаётся сам, в git не попадает). Авторизации в демо нет — вводится только ФИО.
- В карточке аналога: «Сверка характеристик» (запрос ↔ аналог по каждому параметру) и кнопка «Запросить КП» → `POST /api/quote-request`, журнал `GET /api/quote-requests` (демо: хранится в памяти, поставщикам ничего не отправляется).
- PDF только с текстовым слоем; для сканов нужен OCR (не реализован).

## Установка и запуск
```bash
python3 -m venv venv && source venv/bin/activate
pip install fastapi "uvicorn[standard]" rapidfuzz pypdf numpy python-multipart sentence-transformers
python generate_dataset.py        # data/catalog.json, 360 позиций
uvicorn main:app --reload
```
Без нейросети: `KRIT_EMBEDDINGS=lexical uvicorn main:app --reload`.

## Свой каталог (реальные данные)
```bash
python import_catalog.py --template                 # создаст catalog_template.csv с примером
python import_catalog.py мой_каталог.csv            # добавить позиции к data/catalog.json
python import_catalog.py мой_каталог.csv --replace  # заменить каталог целиком
```
Excel → «Сохранить как» → CSV UTF-8. Колонки описаны в начале `import_catalog.py`.

## Оценка точности
```bash
KRIT_EMBEDDINGS=lexical python eval.py
```
Запрос — название импортной позиции, эталон — её `analogue_ids` (120 запросов). На lexical-режиме: top-1 ≈ 87%, top-3 ≈ 99%, ~1 мс на запрос. Эталон строгий (аналог другого бренда с теми же размерами считается ошибкой), на каталоге из синтетических данных — это не замена пилоту на реальных номенклатурах.
